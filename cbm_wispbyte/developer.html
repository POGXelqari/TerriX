GET /api/v1/bank/status

Fetches real-time solvency telemetry, central vault balance, member liabilities, and unencumbered central bank reserves.

HeaderTypeDescription
Authorization string Bearer <cbm_live_token> (Required)
X-CBM-API-Key string Alternative key header if Bearer is not used.
GET /api/v1/members/{username}

Queries sanitized public financial statements, verification badges, total deposited gold, and primary in-game account for a specific clan member.

Path ParameterTypeDescription
username string Registered CBM username (e.g. B8bbq or Alice).
POST /api/v1/donations/declare

Registers a 15-minute pending donation slip. Ideal for Discord bot !donate 50 commands to give players target account instructions.

JSON Body FieldTypeDescription
account_name string CBM username of the donor.
amount_gold number Exact gold amount to send in-game (e.g. 25.0).
message string Optional public message on War Chest Honor Roll.

Official Discord Bot SDK (Python)

Production-ready Python client with pre-built Discord Embed cards for discord.py, disnake, and pycord.

Download cbm_discord_sdk.py ↗ GitHub
✓ Zero 3rd-Party Dependencies ✓ discord.py & disnake Ready ✓ Python 3.8+ Standard Library
# 1. Download cbm_discord_sdk.py into your bot repository # 2. Add CBM slash commands to your bot: import discord from discord.ext import commands from cbm_discord_sdk import CBMClient, CBMDiscordEmbeds bot = commands.Bot(command_prefix="!", intents=discord.Intents.default()) cbm = CBMClient(api_key="cbm_live_YOUR_SECRET_KEY") @bot.tree.command(name="bank", description="View Clan Bank solvency & vault reserves") async def bank(interaction: discord.Interaction): await interaction.response.defer() status = cbm.get_bank_status() embed = CBMDiscordEmbeds.bank_status_embed(status) await interaction.followup.send(embed=embed) @bot.tree.command(name="donate", description="Generate a verified Clan Bank donation slip") async def donate(interaction: discord.Interaction, amount_gold: float): slip = cbm.declare_donation(interaction.user.name, amount_gold) embed = CBMDiscordEmbeds.donation_slip_embed(slip) await interaction.response.send_message(embed=embed) @bot.tree.command(name="balance", description="Check player Clan Bank balance") async def balance(interaction: discord.Interaction, player_name: str): profile = cbm.get_member(player_name) embed = CBMDiscordEmbeds.member_profile_embed(profile) await interaction.response.send_message(embed=embed)
