          POST
          /api/v1/ai/chat
          NVIDIA NIM • Nemotron-3
        

        

          Executes AI reasoning chat completions using NVIDIA NIM infrastructure (default: nvidia/nemotron-3-ultra-550b-a55b, also supporting moonshotai/kimi-k3). Supports Server-Sent Events (SSE) streaming ("stream": true), synchronous completions with automated NVCF 202 status polling, and non-blocking asynchronous jobs ("async": true). Metered via API Credits (1 Credit = 1.00 Gold debited from member deposit balance and converted into unencumbered Clan Reserves) with automatic failure refund.
        

        

          
            
JSON Body FieldTypeDescription

          
          
            

              messages
              array | string
              Array of {"role": "user"|"assistant"|"system", "content": "..."} or single prompt string.
            

            

              model
              string
              Target model identifier (optional, default: nvidia/nemotron-3-ultra-550b-a55b).
            

            

              max_tokens
              number
              Max response tokens (default: 1024, max: 16384).
            

            

              temperature
              number
              Sampling temperature (default: 0.7, range: 0.0 - 2.0).
            

            

              session_id
              string
              Optional. Active chat session UUID. Maintains multi-turn conversation memory, automatically assembles sliding-window history context, and records assistant replies.
            

            

              end_session
              boolean
              Optional. If true, completes inference and permanently prunes the session and associated message history.
            

            

              ttl_seconds
              number
              Optional (default: 3600). Inactivity TTL in seconds before auto-pruning by background garbage collection.
            

            

              stream
              boolean
              Optional. If true, streams responses in real-time using Server-Sent Events (text/event-stream).
            

            

              async
              boolean
              Optional. If true, enqueues non-blocking job returning job_id for asynchronous retrieval.
            

          
        

        

          
        

      


      
      

        

          POST
          /api/v1/ai/sessions
          Stateful Memory
        

        

          Creates a stateful multi-turn AI session with configurable sliding-window context history, idle expiration TTL, and optional persistent system prompt.
        

        

          
            
JSON Body FieldTypeDescription

          
          
            

              title
              string
              Optional. Human-readable title for the chat session.
            

            

              system_prompt
              string
              Optional. Persistent system instructions applied to every turn in the session.
            

            

              model
              string
              Optional (default: nvidia/nemotron-3-ultra-550b-a55b). Model assigned to session.
            

            

              ttl_seconds
              number
              Optional (default: 3600, max: 604800). Inactivity expiration in seconds.
            

            

              max_turns
              number
              Optional (default: 20, max: 100). Maximum turns preserved in sliding context window.
            

          
        

        

          
        

      


      
      

        

          GET
          /api/v1/ai/sessions
        

        

          Lists all active AI chat sessions owned by the authenticated developer account. Automatically triggers opportunistic garbage collection of expired sessions.
        

        

          
            
Query ParameterTypeDescription

          
          
            

              limit
              number
              Optional (default: 50). Maximum number of sessions to return.
            

            

              offset
              number
              Optional (default: 0). Pagination offset.
            

          
        

        

          
        

      


      
      

        

          GET
          /api/v1/ai/sessions/{session_id}
        

        

          Retrieves metadata, active TTL expiration, and chronological message history for a specific AI session. Touches the session to refresh its inactivity TTL. Supports PATCH to update metadata, DELETE or POST /api/v1/ai/sessions/{id}/end for explicit termination, and POST /api/v1/ai/sessions/{id}/clear to wipe message history.
        

        

          
            
Path / ActionMethodDescription

          
          
            

              /api/v1/ai/sessions/{id}
              GET
              Returns session configuration and message turns.
            

            

              /api/v1/ai/sessions/{id}
              PATCH
              Updates title, system_prompt, ttl_seconds, or model.
            

            

              /api/v1/ai/sessions/{id}
              DELETE
              Permanently deletes session and all historical message records.
            

            

              /api/v1/ai/sessions/{id}/end
              POST
              Explicit session termination and cascading deletion (POST alternative for restricted clients).
            

            

              /api/v1/ai/sessions/{id}/clear
              POST
              Clears all turns and message history while keeping the session active.

# 1. Download cbm_discord_sdk.py into your bot repository
# 2. Add CBM slash commands to your bot:

import discord
from discord.ext import commands
from cbm_discord_sdk import CBMClient, CBMDiscordEmbeds

bot = commands.Bot(command_prefix="!", intents=discord.Intents.default())
cbm = CBMClient(api_key="cbm_live_YOUR_SECRET_KEY")

@bot.tree.command(name="bank", description="View Clan Bank solvency & vault reserves")
async def bank(interaction: discord.Interaction):
    await interaction.response.defer()
    status = cbm.get_bank_status()
    embed = CBMDiscordEmbeds.bank_status_embed(status)
    await interaction.followup.send(embed=embed)

@bot.tree.command(name="donate", description="Generate a verified Clan Bank donation slip")
async def donate(interaction: discord.Interaction, amount_gold: float):
    slip = cbm.declare_donation(interaction.user.name, amount_gold)
    embed = CBMDiscordEmbeds.donation_slip_embed(slip)
    await interaction.response.send_message(embed=embed)

@bot.tree.command(name="balance", description="Check player Clan Bank balance")
async def balance(interaction: discord.Interaction, player_name: str):
    profile = cbm.get_member(player_name)
    embed = CBMDiscordEmbeds.member_profile_embed(profile)
    await interaction.response.send_message(embed=embed)

            💬 Temporary Disposable Chatroom API
            Ephemeral & Moderated
          

          Max 100 Messages FIFO
        

        

          A high-performance, real-time disposable messaging platform built for in-match communication and ephemeral group lobbies. All chat histories, uploaded media, and sessions are permanently and irrevocably destroyed upon room closure or after 30 minutes of inactivity.
        

        

          

            
🛡️ Impenetrable Moderation

            
Zero-width character stripping, Cyrillic/Greek homoglyph normalization, XSS escaping, and toxic pattern blocking.

          

          

            
🔒 SSRF-Safe URL Previews

            
Private/loopback/cloud metadata IP filter and 64KB read limit on OpenGraph link embed generation.

          

          

            
⚡ Verified Media Caps

            
Images ≤ 4MB, Videos ≤ 10MB, Files ≤ 5MB. Verified binary magic byte headers; dangerous extensions blacklisted.

          

        

      


      
      

        

          POST
          /api/cbm/chat/create
        

        

          Constructs or joins an ephemeral disposable chatroom. Automatically initializes a 100-message FIFO ring buffer and dedicated ephemeral storage enclave.
        

        

          
            
FieldTypeDescription

          POST
          /api/cbm/chat/check
          Nemotron-3.5-Content-Safety
        

        

          Pre-flight content safety check powered by nvidia/nemotron-3.5-content-safety and L1 regex heuristics. Evaluates message text and optional media attachments before submission to verify compliance.
        

        

          
            
FieldTypeDescription

          
          
            
contentstringText content to evaluate (required)

            
image_datastringOptional base64-encoded image string for multimodal safety classification

          
        

        

          
        

      


      
      

        

          POST
          /api/cbm/chat/send
          AI Moderated Ingress
        

        

          Sends an authenticated message to the disposable room. Supports Dual Authentication: CBM Member credentials (with verified badge and clan tag) or Anonymous Territorial.io player name. Every message passes through the tiered nvidia/nemotron-3.5-content-safety pipeline (L1 slurs → L2 SHA-256 verdict cache → L3 Nemotron 3.5 NIM) before reaching the room buffer and peers.
        

        

          
            
FieldTypeDescription

          
          
            
room_idstringTarget room identifier (required)

            
contentstringMessage text (max 500 characters, supports sticker shortcodes like :gold:)

            
sender_namestringTerritorial.io in-game name (used for Anonymous Territorial Auth)

            
sender_clanstringClan tag for anonymous player (optional)

            
cbm_usernamestringOptional CBM username for authenticated member badge

            
cbm_pinstringOptional CBM 6-digit access PIN (verifies member authenticity)

            
cbm_passwordstringOptional CBM password fallback

            
player_indexintegerOptional Territorial.io player index for in-game canvas speech bubble positioning

            
attachmentsarrayOptional list of uploaded attachment metadata objects
