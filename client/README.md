# TerriX Web Client (GitHub Pages)

A high-performance, fully deobfuscated web client for [Territorial.io](https://territorial.io) hosted on GitHub Pages.

## Why GitHub Pages (`github.io`)?
- **Native Cloudflare Turnstile Resolution**: Cloudflare sitekey `0x4AAAAAAEI8HZoG8nJMzxt1` explicitly whitelists `*.github.io` domains (marked as `validMod` in the game engine).
- **Official Multiplayer Matchmaking**: Generates valid Turnstile tokens inside the user's browser with zero latency and zero proxy costs.
- **Single-Page Zero Dependency**: Runs directly on any modern browser supporting WebGL and WebSockets.
